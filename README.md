# ONLINE-INTERNSHIP-PORTAL
Online Internship Portal built using React and Python enables students to enroll in virtual internships, access learning materials, complete tasks, and track progress. It includes role-based access, task management, and performance evaluation, providing real-world experience in a structured environment.

## How to Run

### Frontend
To run the React frontend:
```bash
cd frontend
npm install
npm start
```

### Backend
To run the FastAPI backend, see the `backend/` directory or `README_DOCKER.md`.
